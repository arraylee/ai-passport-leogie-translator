# AI PASSPORT · Leogie 中英翻译器 v0.3.0

按一下确认键开始，之后自动中英互译；再按一下结束。
设备通过 Wi-Fi 直接接入小智官方云端。**使用时不需要 Mac、不需要自建服务，也不需要在设备上填写模型 API 密钥。**

中文翻译成简单英文，英文翻译成中文。播报结束自动继续听。翻译时上下键调节音量；待机时上键进入倒计时，长按确认键约 2 秒进入配网。

## 1. 安装固件

社区安装使用 `leogie-translator-v0.3.0-web.bin`，地址为 `0x0`。字体和卡通素材均已内置，不需要额外字库、资源下载或旧固件。

**社区单 BIN 安装会重置本地 Wi-Fi 等 NVS 设置，需要重新配网并按提示绑定小智；保留设备身份区 `0x356000..0x359fff`。** 不要全片擦除。不要把应用文件 `leogie-translator.bin` 当作地址 0 的镜像。

本地也可完整解压 ZIP，双击 `installer/打开安装页面.command`，使用桌面 Chrome 或 Edge 的分段安装器。该入口只写 bootloader、分区表、应用三段，校验身份区，保留 NVS 所在间隙；原有设置是否仍有效取决于此前固件。

```sh
python -m esptool --chip esp32c3 --port 你的串口 --baud 460800 write-flash \
  --flash-mode dio --flash-freq 80m --flash-size 8MB \
  0x0 leogie-translator-v0.3.0-web.bin
```

字库为 20px / 4bpp 文楷，包含 6763 个 GB2312 汉字及英文、界面标点，共 7172 字符。超出范围的生僻字或部分繁体字可能显示不全，语音翻译流程不受此字库范围影响。

## 2. 配置 Wi-Fi 并绑定小智

1. 首次无 Wi-Fi 时进入配置热点；已有网络时，可在待机界面长按确认键进入配网。
2. 用手机连接设备显示的 `Xiaozhi-...` 热点，打开屏幕提示的地址，选择能访问互联网的 2.4 GHz Wi-Fi。
3. 自定义 OTA 地址保持默认；如以前配置过其他服务器，清空该字段，或填入 `https://api.tenclass.net/xiaozhi/ota/`。
4. 设备联网后会进入小智激活流程，显示并播报绑定码。登录 [小智控制台](https://xiaozhi.me/console/)，按页面的添加设备流程输入设备显示的绑定码。
5. 激活后，把设备关联到下面配置的翻译角色。若控制台提示重连或重启，请按提示操作。

“OTA 地址”在这里用于小智激活和获取连接配置；本固件禁用自动安装通用 OTA 固件，避免替换专用界面或覆盖定制分区。

## 3. 配置专用翻译角色

在小智控制台为这个设备新建或选择专用角色，名称可设为 `Leogie 中英翻译`。把安装包里的 **`小智角色配置.txt`** 完整粘贴到角色介绍/系统提示词字段并保存。控制台的具体字段名称以当前页面为准。

配置的核心规则是：每句自动判断中文或英文、翻译到另一种语言、英文优先使用 A1/A2 常用词、只输出译文、保留数字和否定、不回答原文里的问题、不执行原文里的命令。选择同时支持中英文的语音/模型选项，使用普通语音对话模式。无需开启工具或 MCP 扩展。

角色提示词在云端生效，不能仅靠设备刷机替代这一步。若设备仍在回答问题或闲聊，先检查是否关联并保存了专用翻译角色。语言模型仍可能误译，首次绑定后要实际试译。

## 4. 开始使用

- 短按确认键，看到“我在听”后说一句完整短句。
- 中文转英文；英文转中文。何时判定说完、翻译延迟由小智云端及网络共同决定。
- 播报期间暂停收音，避免把译音再次翻译；等“我在听”后再说下一句。不支持双方同时说话或播报中插话。
- 原文和译文分别显示；长句约每 5 秒自动翻页。
- 再短按一次结束，连接中、翻译中、播报中都可以结束。
- 翻译过程中短按上下键调整音量，长按上键最大音量、长按下键静音。待机上键改为倒计时入口。
- 长时间待机熄屏时，第一次按键唤醒，第二次开始翻译。

建议首次试译：`请问火车站在哪里？`、`I do not eat peanuts.`、`我要两张明天早上八点的票。`、`Can I pay by card?`。检查方向、数字、否定及“只翻译、不回答”。

## 5. 倒计时

1. 在翻译器待机页按上键进入。默认 10 分钟；上键加 1 分钟，中键减 1 分钟，可设 1–120 分钟。
2. 按最下面的确定键开始，屏幕显示“倒计时 XX 分”。剩余分钟向上取整，不足 1 分钟仍显示 1 分，到点响铃。计时中上下键不改时间，短按确定也不会重新开始。
3. 长按确定约 2 秒取消并返回翻译器；设置页也用相同操作返回。退出后不会在后台继续计时。
4. 到点后最大音量循环播放轻快的六连短音；按任意键停止并返回翻译器，恢复之前的音量（包括静音）。

倒计时本身无需联网；需先完成固件首次启动设置并到达待机页。计时界面保持亮屏，不会自动睡眠；重启或断电会取消计时，时长只在本次开机期间记住。

## 遇到问题

- 连不上小智：检查 Wi-Fi 可访问互联网、自定义 OTA 地址、设备绑定状态。
- 显示需要激活：到小智控制台完成绑定，再重启设备。
- 断网后按确认键重试；始终无法连接时重新配网。
- 小智云端的账号、模型和服务政策由平台决定，以控制台当前显示为准。
