## 2026-10-17 USB 实机检查与修复

首次安装写入与哈希校验成功，但设备在 ES8311 驱动初始化时断言失败并反复重启。根因是专用板配置的输入 16 kHz、输出 24 kHz，与该驱动的共享时钟要求冲突。修复为硬件输入/输出均 24 kHz；现有 AudioService 将录音转换为 16 kHz 后编码上传。新增采样率约束回归测试，已确认修复前失败、修复后通过。

修复版编译成功，138 项主机测试通过（1 项跳过）。首次全套测试的 6 项 CI 测试因子进程找不到 python 而报错，补齐虚拟环境 PATH 后完整重跑通过。修复版应用已写入 0x10000 并独立读回摘要校验通过，其他三个镜像未变化。设备身份区与首次写入前逐字节相同。启动日志中音频初始化成功，并进入 Wi-Fi 配网。

完整物理交互和云端翻译尚未验收，因此包内总验收标志仍未置为完成；实际写入、身份校验及启动状态另记在 evidence 中。
